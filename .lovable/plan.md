# My Tento mobile booking app

## Goal
Build an attractive, modern mobile-first booking experience from the supplied client brief, using the selected royal blue and orange palette, Sora/Manrope typography, and service-grid home screen.

## What will be built
- Branded My Tento home screen with location selector, greeting, four primary service cards, promotional booking banner, nearby providers, and bottom navigation.
- Interactive booking flow for Tent, Decoration, Catering/Bartan, and Cab: service selection, event location, date/time, guest count, provider/package choice, payment option, and confirmation.
- Useful booking states including upcoming booking summary and success confirmation with WhatsApp/SMS notification messaging.
- Mobile-first responsive presentation that also looks polished on desktop.
- Content and pricing examples grounded in the uploaded requirement document; no live payments, login, notifications, provider panel, or admin data system in this first visual prototype.

## Visual direction
- Royal blue anchors trust and navigation; orange highlights event energy and primary actions.
- Sora headings with Manrope body copy.
- Crisp service tiles, restrained shadows, compact corners, clear icons, and subtle transitions.
- Use the supplied MyTento logo artwork as brand reference while recreating a clean app-ready identity treatment.

## Technical details
- Implement the experience at `/` with local interactive state.
- Define semantic design tokens and motion centrally in the global stylesheet.
- Add app-specific metadata and mobile-safe responsive layouts.
- Verify the main booking flow and check desktop/mobile rendering in the live preview.
